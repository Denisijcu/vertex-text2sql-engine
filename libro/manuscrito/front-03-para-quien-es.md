# Para quién es este libro

Este libro es para ti si:

- **Eres desarrollador** y quieres un modelo propio que haga una tarea concreta, y la haga bien,
  en vez de depender de un asistente general en la nube.
- **Tienes una GPU modesta.** Seis gigas bastan. Todo el proyecto se hizo en una GTX 1660 Ti.
- **Trabajas con datos que no pueden salir de casa**: de clientes, de pacientes, de empleados.
  Quieres que alguien pueda preguntarle a la base de datos sin mandarla a ningún servidor ajeno.
- **Piensas en producto.** No te basta con que el modelo funcione en una demo: quieres saber cómo
  se mide, cómo se protege la base de datos de sus errores y cómo se publica para que otros lo
  usen.
- **Quieres ofrecer modelos afinados a tus clientes**, y necesitas un proceso que puedas repetir
  y defender con números.

## Qué necesitas saber de antes

- **Programar en Python** y moverte por la línea de comandos sin miedo. Los ejemplos son en
  Python y PowerShell, en Windows 11.
- **SQL básico**: qué es un `SELECT`, un `WHERE`, un `GROUP BY`. No hace falta ser experto: el
  modelo escribe el SQL, pero tú tienes que poder leerlo y juzgarlo.
- **Nociones de qué es un modelo de lenguaje.** Los conceptos clave se explican donde aparecen, y
  hay un glosario al final.

Si ya leíste *Vertex-Core*, reconocerás algunas ideas del entorno y del entrenamiento. Este libro
no depende de aquel: todo lo necesario está aquí.

## Qué NO es este libro

- **No es un curso de SQL.** Si necesitas aprender SQL desde cero, este no es el lugar.
- **No es un libro de teoría.** Hay teoría donde hace falta para entender una decisión, pero el
  corazón es práctico: este es el código, esto es lo que medí, esto es lo que falló.
- **No promete un modelo perfecto.** Promete un modelo medido, con sus fallos documentados y un
  sistema alrededor que impide que esos fallos hagan daño.

Si te reconoces en la primera lista, estás en el lugar correcto.
